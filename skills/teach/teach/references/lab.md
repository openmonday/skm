# Hands-on Lab (`lab/`)

Use `lab/` when the lesson's objective requires writing code, editing configuration, or debugging rather than explaining a concept.

1. Set up minimal starter files inside `.lessons/<topic>/<lesson-slug>/lab/`, along with a quick check script if useful, using existing tools without adding project dependencies.
2. Ask the user to edit or run their solution in `lab/`.
3. Verify that their solution handles the objective's main case and edge cases before concluding the conversation step.
4. When writing `<lesson-slug>.md`, link the key files in `lab/` and include the verification command or solution summary so the lesson remains runnable.
